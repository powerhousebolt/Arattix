Module: Auth

The Auth module handles authentication with the Arattai platform. It includes QR code login, session persistence, and token-based auth (placeholder for future use).

QRLogin

Runs the QR code login flow: fetches a QR code from the Arattai accounts server, optionally prints it in the terminal, and polls until the user scans it with the Arattai app. Expired QR codes are replaced automatically.

new QRLogin(session, options?)
session
AxiosInstance — Axios instance with cookie jar.
options.showQr
boolean — Print the QR code to the terminal. Default: true. Set false to keep the QR (a login credential) out of logs.
initiateLogin() async
initiateLogin(): Promise<boolean>
Runs the whole flow (request QR, poll every 5 s) and resolves true once the QR is approved.
requestQrData() async
requestQrData(): Promise<object>
Requests a new QR code. The string to render is qrResp.qrcodeauth.oneauth_url.
pollOnce() async
pollOnce(): Promise<'pending' | 'refreshed' | 'authenticated'>
Checks the QR status once (requesting a QR first if none is active). 'refreshed' means the old QR expired and a new one is in qrResp. Use it to drive your own loop, with your own deadline and UI. 
// Show the QR somewhere other than the terminal (e.g. a web page)
const { session } = new ArattixBot({ isShowQr: false });
const qr = new QRLogin(session, { showQr: false });
await qr.requestQrData();
render(qr.qrResp.qrcodeauth.oneauth_url);

let status;
while ((status = await qr.pollOnce()) !== 'authenticated') {
  if (status === 'refreshed') render(qr.qrResp.qrcodeauth.oneauth_url);
  await new Promise((r) => setTimeout(r, 5000));
}

SessionManager

Manages session persistence. Saves the cookie jar to cookies.json and request headers to headers.json (both in the working directory) after a successful login, and tests them on startup to skip QR scanning when possible. Both files grant access to the account: keep them private.

new SessionManager(session)
session
AxiosInstance — Axios instance with cookie jar.
testCookies() async
testCookies(): Promise<boolean>
Loads the saved session and checks it against Arattai. Returns true only for a 2xx answer; the redirect to the login page that an expired session receives counts as invalid. Returns false when either file is missing.
saveSession() async
saveSession(): Promise<void>
Save the session to cookies.json and headers.json.

Authentication Flow

1. ArattixBot.loginWithQr() called
2. SessionManager.testCookies() — check saved session
   ├─ Valid → return Bot (skip QR)
   └─ Invalid → continue
3. QRLogin.initiateLogin() — fetch & display QR code (if isShowQr)
4. User scans QR with Arattai mobile app
5. SessionManager.saveSession() — persist cookies.json + headers.json (only on success)
6. Return authenticated Bot instance
Note You typically don't use these classes directly. Use ArattixBot.loginWithQr() which handles the full flow automatically.
